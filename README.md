Kişisel CV Web Sitesi

Bu proje, kendimi tanıtmak, yeteneklerimi, eğitim bilgilerimi ve deneyimlerimi paylaşmak amacıyla Python kullanılarak geliştirilmiş kişisel CV web sitesidir.

Kullanılan Teknolojiler
Python
HTML
CSS
JavaScript (kullanıldıysa)
Özellikler
Kişisel bilgiler
Eğitim bilgileri
Yetenekler
Projeler
İletişim bilgileri
Kurulum

Projeyi bilgisayarınıza indirin:

bash
git clone https://github.com/Qeerzz/my_cv


Proje klasörüne girin:

bash
cd main.py


Gerekli kütüphaneleri yükleyin:

bash
pip install -r requirements.txt


Projeyi çalıştırın:

bash
python app.py

Amaç

Bu projeyi Python ile web geliştirme becerilerimi geliştirmek ve kendimi dijital ortamda tanıtmak amacıyla oluşturdum.
